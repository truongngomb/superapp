# UI Kit

Shared Design System and Component Library.

## Overview
- **Stack:** React, Radix UI, Tailwind CSS
- **Components:** Atoms, Molecules, Layouts

## Documentation
- [Architecture](../../_bmad-output/architecture-ui-kit.md)

## Usage

```typescript
import { Button, Card } from '@superapp/ui-kit';

function MyComponent() {
  return (
    <Card>
      <Button>Click Me</Button>
    </Card>
  );
}
```
